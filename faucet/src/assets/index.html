Q Qnero testnet faucet

Testnet funds

This pays QNR as a shielded note to one qn1 address, once per address per .

Qnero has no transparent transfer, so a drip is a shielded payment and a shielded payment is a zero-knowledge proof. The faucet proves one at a time: it takes about ten seconds to prove and then up to one block, which is two minutes, to settle. The page waits for both.

What it does not do

  • It pays one address at a time and refuses a second claim inside the cooldown.
  • It cannot pay transparent QNR. There is no transparent transfer on this chain, so the note lands in the shielded pool and a wallet has to scan for it.
  • These tokens are worth nothing. The network may be reset without notice, which takes every balance on it with it.
